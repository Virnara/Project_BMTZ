## 📌 Deskripsi Proyek
Repository ini berisi dokumentasi spesifikasi kebutuhan perangkat lunak (*Software Requirements Specification*) untuk subsistem **Donasi Berulang dan Kanal Pembayaran Digital** Baitulmal Tazkia. 

Subsistem ini bertugas mengelola kesediaan donasi berulang donatur, memproses penagihan berkala melalui Payment Gateway (Artivisi), serta menyediakan integrasi data transaksi untuk penerimaan donasi (Kelompok 1), rekonsiliasi (Kelompok 5), dan komunikasi donatur (Kelompok 11).

---
